Cloud Resume + Live Operations Dashboard

A hands-on AWS portfolio project built to demonstrate cloud support skills across static hosting, secure content delivery, serverless APIs, database updates, monitoring, CI/CD deployment and troubleshooting.

AWS S3 CloudFront Route 53 ACM API Gateway Lambda DynamoDB CloudWatch GitHub Actions Origin Access Control

Project Overview

This project is a live AWS-hosted portfolio website. It uses CloudFront in front of a private S3 bucket, a serverless visitor counter built with API Gateway, Lambda and DynamoDB, and a live dashboard to show visitor metrics and cloud monitoring concepts.

Architecture

User Browser | v Route 53 + ACM | v CloudFront Distribution | v Private S3 Bucket with Origin Access Control | +-------------------------------+ | v Portfolio Website | v API Gateway ---> Lambda ---> DynamoDB | v CloudWatch Metrics

AWS Services Used

S3 + CloudFront

Hosts the static portfolio and delivers content securely through CloudFront.

Origin Access Control

Keeps the S3 bucket private while allowing CloudFront to access the required files.

API Gateway + Lambda

Provides a serverless API used by the visitor counter and dashboard.

DynamoDB

Stores total visitor count and unique visitor tracking records.

CloudWatch

Used for logs, custom metrics and dashboard visibility.

GitHub Actions

Automates deployment to S3 and CloudFront cache invalidation after updates.

Support Engineering Skills Demonstrated

  • Configured AWS services across hosting, CDN, API, database and monitoring layers.
  • Troubleshot CloudFront and S3 access issues while improving the private bucket design.
  • Debugged Lambda and API Gateway behaviour using logs and response testing.
  • Worked through DynamoDB update expression issues, including reserved keyword handling.
  • Created CloudWatch metrics and dashboard views for visitor activity.
  • Used GitHub Actions secrets and CI/CD to deploy updates consistently.

Troubleshooting Wins

403 Access Issues

Investigated S3 and CloudFront access problems while configuring secure private bucket access.

Lambda/API Errors

Reviewed API behaviour and logs when testing visitor counter requests.

CloudFront Cache

Used cache invalidations to make updated website files appear after deployment changes.

Security Headers/CSP

Worked through browser-side security restrictions affecting scripts, styles and API calls.

Why This Project Matters for AWS Cloud Support

This project practises the same thinking used in cloud support: understanding how services connect, reading symptoms, checking configuration, reviewing logs, isolating causes, documenting fixes and improving reliability over time.
